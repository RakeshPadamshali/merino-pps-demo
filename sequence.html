The sequencing rules
1
Light to dark on a set. Each cycle a mould set may press only shades at or above the darkest shade it pressed since its last cleaning — a dark decor leaves resin and pigment on the plate that would mark a lighter one.
2
Reset = a cleaning pass. To go lighter, one daylight of that set runs a cleaning pass with no output for one cycle — or the lighter work goes to another set of the same texture that is still light.
3
One texture per daylight, one cure band per cycle. Changing a daylight's texture is a plate swap ( min); changing the cure profile is a band change.
4
Campaigns. The weighted plan keeps a mounted texture running while its work is worth more than the changeover, and a texture only gets a new daylight when it has enough released work to pay for the swap — Merino today keeps a texture only while it appears in the next lines of the fixed list.
